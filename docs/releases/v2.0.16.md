# Prism 2.0.16

本版提供运维台在线更新，并拆分模型查询接口，减小列表响应和加载依赖。

2.0.14 和 2.0.15 的打包均未生成正式安装包；本版保持已应用迁移的原始校验值。

- 运维台新增系统更新：检查版本、下载校验、查看迁移计划、确认安装及查询结果。
- 更新源存入数据库，支持新增、修改、启停和优先级；仓库只内置 GitHub 来源。
- 独立更新服务执行程序替换、必要迁移和健康检查；Linux 安装包附更新器及配置模板。
- `/v1/models` 只返回摘要；`/v1/models/:code` 返回详细能力及各类模型统一价格。
- `/v1/models/availability` 批量返回成功率、状态、生成耗时和时间段记录，可独立刷新。
- 修正更新页长字段溢出，完善运行状态时间段数据及接口文档。

下游读取价格和详细能力时应改用详情接口；读取 `availability` 时应改用运行状态接口，按模型 `id` 关联。

文档：[模型接口说明](../MODELS_API_SPLIT.md)、[图片接入](../IMAGE_API_GUIDE.md)、[完整接入指南](../PRISM_API_GUIDE_20261009.md)、[在线更新](../system-update.md)。

本版新增更新源配置表和运行状态 `buckets` 列；已执行对应迁移的实例无需重复执行。在线安装前以页面列出的实际待迁移计划为准。
